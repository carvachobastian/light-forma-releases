# Light Forma releases

Downloads for Light Forma, music-driven generative visuals for macOS.
This repository holds builds only; there is no source code here.

Download the latest `.dmg` from the
[Releases page](https://github.com/carvachobastian/light-forma-releases/releases/latest).

## Requirements

- A Mac with Apple Silicon (M1 or later).
- macOS 14 or later.

## First launch

Light Forma is not signed with an Apple Developer ID yet, so macOS blocks it
the first time:

1. Open the `.dmg` and drag Light Forma into Applications.
2. Open Light Forma. macOS says it cannot verify the app. Click Done.
3. Open System Settings > Privacy & Security, scroll down, and click
   Open Anyway next to the Light Forma message. Confirm with your password.

After that it opens normally. Each new version needs the same steps once.
